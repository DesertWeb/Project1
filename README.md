You can run this project online or locally on your own machine.

## Run Online

Try the app directly in your browser
https://project1-6igs.onrender.com/

## Run Locally

### Get the project
Clone the repository with Git or download it as a ZIP file:

git clone https://github.com/DesertWeb/Project1.git


### Install Node.js
If you don’t have it yet, download and install Node.js from
https://nodejs.org/


### Start the application
Open your terminal in the project folder and run:

node app.js


### View in your browser
Open http://localhost:3000
 to access the app.
